<h1>Optimus Sun</h1>
<p>
  O projeto <strong>Optimus Sun</strong> tem como objetivo auxiliar no <strong>dimensionamento de sistemas fotovoltaicos</strong>, relacionando modelos de inversores e módulos solares para verificar sua compatibilidade elétrica e operacional.
</p>

<h2>Descrição Geral</h2>
<p>
  Desenvolvido em <strong>Python</strong> com interface <strong>Tkinter</strong> e banco de dados <strong>SQLite</strong>, o sistema permite selecionar inversores e módulos pré-cadastrados, analisando automaticamente a quantidade ideal de módulos por MPPT e as condições elétricas de operação. 
  O objetivo é simplificar o processo de projeto, evitando combinações incompatíveis e fornecendo informações completas sobre limites de tensão, corrente e potência.
</p>

<h2>Funcionalidades Implementadas</h2>
<ul>
  <li>Banco de dados <strong>SQLite</strong> com informações detalhadas de inversores e módulos fotovoltaicos.</li>
  <li>Interface gráfica em <strong>Tkinter</strong> para seleção de equipamentos e exibição dos resultados.</li>
  <li>Verificação de compatibilidade entre inversor e módulo com base nos parâmetros elétricos.</li>
  <li>Cálculo automático da quantidade máxima e mínima de módulos por string e por MPPT.</li>
  <li>Exibição de resultados organizados por MPPT e por inversor completo.</li>
  <li>Gráficos interativos com <strong>Matplotlib</strong> explicando os limites elétricos e as condições de operação.</li>
  <li>Resumo geral com capacidades, potências e restrições de cada arranjo.</li>
</ul>

<h2>Tecnologias Utilizadas</h2>
<ul>
  <li><strong>Python</strong> — linguagem principal de desenvolvimento.</li>
  <li><strong>Tkinter</strong> — biblioteca para criação da interface gráfica.</li>
  <li><strong>SQLite</strong> — banco de dados local para armazenamento de equipamentos.</li>
  <li><strong>Matplotlib</strong> — geração de gráficos comparativos.</li>
  <li><strong>Excel</strong> — utilizado para organização e conversão de dados de entrada.</li>
</ul>
