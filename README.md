Optimus Sun é uma ferramenta para dimensionar a quantidade de módulos a ser ligados a inversores fotovoltaicos. Até a versão 2.3.7, conta com o cadastro de mais de 250 inversores e módulos, onde é possível escolher os dispositivos desejados. O aplicativo considera como padrão uma sobrecarga de 50% nos inversores e ele indica fatores limitantes como a corrente de operação, corrente de curto-circuito, tensão de operação e tensão de circuito aberto, entre outros parâmetros
O aplicativo apresenta compensação térmica dos módulos e faz calculos considerando a tensão de potência máxima do inversor, minimizando o derating por tensão CC
O banco de dados apresenta dados adicionais, não relevantes para os calculos, como tamanho, peso, tipos de comunicação, etc, pois podem ser úteis para alguma outra aplicação
Tem marcas de inversores como Weg, Huawei, Goodwe, FoxEss e inversores de marcas como Trina, Risen, Weg, Longi, etc
Aplicação desenvolvida juntamente com a empresa Ecopower, onde é utilizada para facilitação dos processos, projetos e execuções
