Optimus Sun é uma ferramenta para dimensionar a quantidade de módulos a ser ligados a inversores fotovoltaicos. Até a versão 2.3.7, conta com o cadastro de mais de 250 inversores e módulos, onde é possível escolher os dispositivos desejados. O aplicativo considera como padrão uma sobrecarga de 50% nos inversores e ele indica fatores limitantes como a corrente de operação, corrente de curto-circuito, tensão de operação e tensão de circuito aberto, entre outros parâmetros
