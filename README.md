# Optimus Sun

Ferramenta de apoio ao dimensionamento de sistemas fotovoltaicos,
focada na compatibilidade entre inversores e módulos.

## Objetivo
Auxiliar o projetista a validar:
- quantidade máxima de módulos por MPPT
- limites elétricos em diferentes condições
- aproveitamento de potência
- arranjos eficientes de strings

## Funcionalidades implementadas
- Banco de dados SQLite de inversores e módulos
- Seleção interativa de inversor e módulo
- Cálculo de limites por MPPT
- Visualização comparativa de condições elétricas
- Interface gráfica em Python (Tkinter)

## Tecnologias
- Python
- Tkinter
- SQLite
- Matplotlib
